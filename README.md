
## Powered by Gemma 4
ErrorSaathi uses **Google Gemma 4** (`gemma-4-26b-a4b-it` for fast analysis, `gemma-4-31b-it` for deep reasoning) via the Gemini API.
Gemma 4 does the core work: classifying errors, finding root causes from CI logs and PR diffs, generating safe fix steps,
reviewing risky commands, and explaining everything in English or Roman Urdu.
